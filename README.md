# SCured — Student Library Duty Management System

SCured is a web-based Student Library Duty and Social Contract Management System developed for Pamantasan ng Lungsod ng Valenzuela (PLV). Built using **Ionic Angular (NgModules)**, it simplifies student duty reservations, scheduling, attendance monitoring, and service record management through an organized and user-friendly interface.

## Demo Instructions

To run the project locally, follow these steps:

**1. Clone the repository**
```bash
git clone <repository-url>
cd SCured
```

**2. Install dependencies**
```bash
npm install
```

**3. Install Ionic CLI (if not installed)**
```bash
npm install -g @ionic/cli
```

**4. Run the application**
```bash
ionic serve
```

**5. Open the demo**

Visit `http://localhost:8100` in your browser, or use the local URL displayed in the terminal.

Explore student duty reservations, attendance monitoring, and the admin dashboard. Demo authentication and sample data may be used depending on the current implementation.
